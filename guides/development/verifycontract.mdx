## Introduction

This guide shows how to verify a deployed smart contract on Quai Network's official mainnet block explorer, **[Quai Explorer (`explorer.qu.ai`)](https://explorer.qu.ai/)**.

Verifying your smart contract publishes its source code and ABI on-chain so users and developers can audit the bytecode and interact with **Read** and **Write** contract tabs directly inside the explorer.

<Note>
  For **Orchard Testnet** deployments (`chainId: 15000`), use the Orchard explorer at [orchard.quaiscan.io](https://orchard.quaiscan.io/).
</Note>

## Supported Verification Methods on Quai Explorer

[Quai Explorer](https://explorer.qu.ai/) supports three contract verification workflows:

- **Solidity (Standard JSON Input)** *(recommended)* — Upload the compiler's Standard JSON input (or the IPFS metadata file generated by `@quai/hardhat-deploy-metadata`).
- **Solidity (Flattened Source Code)** — Paste single-file flattened Solidity source code along with compiler version and optimization flags.
- **Sourcify Import** — Automatically import verified contract metadata and source files from Sourcify.

## Prerequisites

To deploy contracts with IPFS metadata and verify them on Quai Explorer, you'll need:

| Dependency | Description |
| :--- | :--- |
| [**Node.js**](https://nodejs.org/en/download/) | JavaScript runtime environment (use the LTS version). |
| [**hardhat-example**](https://github.com/dominant-strategies/hardhat-example) | Sample Hardhat project with contracts and deploy scripts for Quai Network. |
| [**hardhat-deploy-metadata**](https://github.com/dominant-strategies/hardhat-deploy-metadata) | Hardhat plugin that pushes contract metadata to IPFS during deployment. |
| [**Quais SDK**](https://www.npmjs.com/package/quais) | JavaScript/TypeScript library for interacting with Quai Network. |

## Walkthrough

This walkthrough follows the [Deploy with Solidity](/guides/development/solidity) guide using the [hardhat-example](https://github.com/dominant-strategies/hardhat-example) repository.

### 1. Deploy a Smart Contract

Following the [Deploy with Solidity](/guides/development/solidity) guide, deploy a smart contract with IPFS metadata enabled:

```bash
npx hardhat run scripts/deployERC20.js
```

Example output:

```text
File added with CID: QmPCoBa1bCFmRoTD7GuexJqBAy7pqg8J4b8B48q5DgxUEV
Original IPFS hash found in bytecode: QmPCoBa1bCFmRoTD7GuexJqBAy7pqg8J4b8B48q5DgxUEV
Metadata JSON for ERC20 saved to /../hardhat-example/Solidity/metadata/ERC20_metadata.json
Transaction broadcasted:  0x0032004cc6a910b8733ad9502caa315beb74f3409bee2b481116bddfb9c8880d
Contract deployed to:  0x0015dFe3280783CD9b126D8E0ccc728B6490b2b2
```

Capture both your deployed **contract address** and the **IPFS CID** uploaded to `ipfs.qu.ai`.

### 2. Download the Formatted IPFS Metadata

When using `@quai/hardhat-deploy-metadata`, download the formatted metadata JSON from `ipfs.qu.ai` using your deployment's CID:

```bash
curl https://ipfs.qu.ai/ipfs/[YOUR_IPFS_METADATA_HASH] > ipfsMeta.json
```

### 3. Verify & Publish on Quai Explorer

1. Open **[Quai Explorer (`explorer.qu.ai`)](https://explorer.qu.ai/)** and navigate to the **Contract Verification** page (or search your deployed contract address and open its **Contract → Verify & Publish** tab).
2. Enter your deployed **Contract Address** and select the **License** matching the `SPDX-License-Identifier` in your source file.
3. Choose **Solidity (Standard JSON Input)** as the verification method and select the exact **Solidity Compiler** version used to compile your contract (or choose **Flattened Source** / **Sourcify** if preferred).
4. Upload `ipfsMeta.json` (or your Standard JSON input file) and click **Verify & Publish**.

Once verified, your contract page on [explorer.qu.ai](https://explorer.qu.ai/) will display a verified badge, full source code, ABI, and interactive **Read Contract** and **Write Contract** tabs.

<Tip>
  Need programmatic verification or contract ABI queries? Check out the [Quai Explorer API](https://explorer.qu.ai/api).
</Tip>
