## 主网基础设施

| 资源 | 描述 |
| :--- | :--- |
| [Quai Explorer](https://explorer.qu.ai/) | Quai 网络主网官方区块浏览器（支持区块、workshare、代币与合约验证）。 |
| [Quai Explorer API](https://explorer.qu.ai/api) | 开发者 API 门户，用于查询主网区块、账户、代币及合约验证状态。 |
| [供应仪表板](https://supply.qu.ai/) | 实时查看 QUAI 与 Qi 流通供应量、Polaris/Singularity 创世销毁及发行时间表。 |
| [SOAP 仪表板](https://soap.qu.ai/) | 实时查看 SOAP 项目合并挖矿补贴流入及累计销毁的 QUAI。 |
| [网络统计](https://stats.quai.network/) | 主网节点数量与算力统计仪表板。 |
| [GraphQL 端点](https://graph.quai.network/) | 主网 GraphQL 端点，支持通过筛选与分页查询链上数据。 |
| [转换仪表板](https://conversions.quai.network/) | 协议实时的 QUAI ↔ Qi 转换汇率。 |
