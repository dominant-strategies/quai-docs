## Mainnet Infrastructure

| Resource | Description |
| :--- | :--- |
| [Quai Explorer](https://explorer.qu.ai/) | Official block explorer for Quai Network mainnet (blocks, workshares, tokens, contract verification). |
| [Quai Explorer API](https://explorer.qu.ai/api) | Developer API portal for querying mainnet blocks, accounts, tokens, and verification status. |
| [Supply Dashboard](https://supply.qu.ai/) | Live QUAI & Qi circulating supply, Polaris/Singularity genesis burns, and emission schedules. |
| [SOAP Dashboard](https://soap.qu.ai/) | Live Project SOAP merge-mining subsidy inflows and cumulative QUAI burned. |
| [Network Statistics](https://stats.quai.network/) | Mainnet node count and hashrate statistics dashboard. |
| [GraphQL Endpoint](https://graph.quai.network/) | Mainnet GraphQL endpoint for querying chain data with filters and pagination. |
| [Conversions Dashboard](https://conversions.quai.network/) | Live protocol QUAI ↔ Qi conversion rates. |
