## Polaris フォーク（2026年10月）

**Polaris フォーク**（`go-quai v0.57.0`、2026年10月13日に有効化、更新後のアンロックスケジュールは 2026年10月30日以降に確定）は、プロトコルレベルのアドレススキップを実装し、Quai 創設者および開発企業 Dominant Strategies に割り当てられていた残りの将来ジェネシス配分をすべて永久に焼却しました。

### 主な数値と構造的影響

- **永久焼却されたトークン：** 創設者および Dominant Strategies が放棄した **236,456,538 QUAI**。
- **累計ジェネシス焼却量（Singularity ＋ Polaris）：** 当初の 3,000,000,000 ジェネシス配分から **1,903,616,522 QUAI（約 19.0 億）** を永久除去し、調整後ジェネシスベースラインを **1,096,383,478 QUAI** へ削減。
- **流通供給比率：** 総供給量に対する割合が **約 77% → 約 93%** へ即座に上昇。
- **年間ジェネシスインフレ率：** **約 13% → 年率 4% 未満** へ大幅削減。
- **年間総インフレ率（SOAP を加味）：** **約 18% → 年率 9% 未満** へ低下。
- **月次ジェネシスアンロック：** **月間約 1,300 万 → 約 370 万 QUAI** へ急減。
- **残りの未ベスティング残高：** **約 3.27 億 → 約 9,040 万 QUAI（7.2%）** へ削減され、**2029年初頭**までにジェネシスベスティングが完全完了、**2028年11月**にはプルーフ・オブ・ワーク・マイニング過半数へ到達する軌道に。

## Singularity フォーク（2026年3月）

2026年3月19日に `go-quai v0.51.0` を通じて **Prime ブロック 1,530,500** で有効化された **Singularity フォーク**は、Quai の金融政策とワークシェアのスループットの両方を抜本的に再構築しました。

1. **多者合意によるジェネシス焼却：** 投資家、Dominant Strategies、Quai Foundation が自主的に合意し、**1,667,159,984 QUAI**（残りの将来ジェネシスアンロックの 81.1%）をスキップ・永久焼却。既定ジェネシスベースラインを **3,000,000,000 QUAI** から **1,332,840,016 QUAI** へ引き下げました。
2. **ワークシェア包含上限の倍増（16 → 32）：** [Project SOAP](/jp/learn/advanced-introduction/soap) における外部 PoW の参加とノードの資本効率を高めるため、`v0.51.0` では 1 ブロックあたりのワークシェア上限を倍増しました。
   - **ブロックあたりの総ワークシェア数：** `16` → **`32`**
   - **ブロックあたりの SHA-256 ワークシェア数：** `8` → **`16`**
   - **ブロックあたりの Scrypt ワークシェア数：** `8` → **`16`**
3. **標準供給式の確立：** [supply.qu.ai](https://supply.qu.ai) でリアルタイム追跡される透明な供給フレームワークを確立しました。
   $$\text{Total Supply} = \text{Genesis Unlocks} + \text{Mining Emissions} - \text{SOAP Burns}$$

## 中間クライアント改善（`v0.52.0` – `v0.55.0`）

Singularity と Polaris の間、段階的な `go-quai` リリースによって SOAP の経済性と報酬の安定性がさらに強化されました。

- **`v0.52.0`：** メインネット API の安定性向上および Singularity 後の RPC 機能強化。
- **`v0.53.0`：** **SHA 換算の報酬正規化**を導入し、BCH、LTC、DOGE、RVN に加えてネイティブなビットコイン証明構造を SOAP の AuxPoW 会計で受け入れる準備を整備。
- **`v0.54.0`：** ブロック報酬、難易度調整、QUAI ↔ Qi 変換ダイナミクスを平滑化するためのより長期の**指数移動平均（EMA）**を実装。
- **`v0.55.0`：** Polaris（`v0.57.0`）に向けたノード同期およびインフラ最適化の継続。

## Project SOAP（2025年12月）

2025年12月にローンチされた **Subsidized Open-market Acquisition Protocol（SOAP）** は、Quai を単一アルゴリズムの GPU チェーンから、KawPoW GPU に加えて SHA-256 および Scrypt ASIC によって保護されるマルチアルゴリズム・プルーフ・オブ・ワーク・ネットワークへと進化させました。マージマイニングされた親チェーン報酬が売り圧力になるのを許すのではなく、SOAP は親チェーンのコインベース補助金の **100%** をプロトコル管理アドレスにルーティングし、公開市場で QUAI を購入して永久焼却します。

詳細は [Project SOAP 技術概要](/jp/learn/advanced-introduction/soap) をご覧いただき、リアルタイムの焼却状況は [soap.qu.ai](https://soap.qu.ai) でご確認ください。
