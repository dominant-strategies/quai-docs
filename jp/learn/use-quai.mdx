Quai ネットワークは 2018 年、プルーフ・オブ・ワークをスケーリングするための階層型マージマイニング・チェーンの構想とスケーラブルな PoW アーキテクチャの設計から始まりました。
[Dr. K](https://x.com/mechanikalk) の研究と GridPlus の取り組みから生まれ、テキサス大学オースティン校での研究プロジェクトとして発展しました。2019 年には NSF（米国国立科学財団）の支援を受けた研究によって構想が進展し、開発企業 Dominant Strategies の設立へとつながりました。
以降、エントロピー最小値証明（[PoEM](https://arxiv.org/abs/2303.04305)）、二重トークンモデル（Qi と Quai）、[Project SOAP](/jp/learn/advanced-introduction/soap) によるマルチアルゴリズム・マイニング、AFT 2026 に採択されたワークシェア配分研究、そして [Singularity および Polaris](/jp/learn/tokenomics/protocol-upgrades) のハードマネー・アップグレードといった革新を重ねてきました。Quai ネットワークのメインネットは 2025年2月4日のジェネシスブロックをもって稼働を開始しました。

## Quai をマイニング

Quai ネットワークは KawPoW マイニングアルゴリズムを採用し、SHA-256 および Scrypt とマージマイニングされています。マイナーは QUAI または QI のいずれをマイニングするか選択できます。

### ソロマイニング（StratumX）

手数料ゼロ・KYC 不要・完全セルフカストディで分散型マイニングインフラに接続でき、Qi マイニングや[ロックドマイニング報酬](https://docs.qu.ai/learn/advanced-introduction/liquid-mining-tokens)などのカスタマイズにも対応しています。

| リソース | タイプ | 特徴 |
| :--- | :--- | :--- |
| [StratumX.org](https://www.stratumx.org/) | プラットフォーム | SHA-256、Scrypt、KawPoW リグを直接接続（ノード不要） |
| [収益計算ツール](https://www.stratumx.org/calculator) | ツール | 各アルゴリズムの収益性を試算 |
| [セットアップガイド](https://docs.qu.ai/guides/client/solo-mining) | ドキュメント | KawPoW、Scrypt、SHA-256 による QUAI マイニング用 StratumX ノードの構築方法 |

### マイニングリソース

マイナー向けの必須ガイドとデータです。

| リソース | カテゴリー | 説明 |
| :--- | :--- | :--- |
| [マイニングガイド](https://docs.qu.ai/guides/miner/) | ドキュメント | SHA-256、Scrypt、KawPoW 向けガイド（HiveOS、Ubuntu、Docker） |
| [プール・ソフトウェア](https://docs.qu.ai/guides/miner/pools-software) | 一覧 | 利用可能なマイニングプールとソフトウェアの包括的リスト |
| [go-quai クライアントセットアップ](https://docs.qu.ai/guides/client/node) | ドキュメント | Quai ノードの構築・運用ガイド |
| [MiningPoolStats](https://miningpoolstats.stream/quai/) | データ | リアルタイムのハッシュレート分布とプール統計 |
