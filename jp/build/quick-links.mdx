## メインネット・インフラストラクチャ

| リソース | 説明 |
| :--- | :--- |
| [Quai Explorer](https://explorer.qu.ai/) | Quai ネットワーク・メインネットの公式ブロックエクスプローラー（ブロック、ワークシェア、トークン、コントラクト検証）。 |
| [Quai Explorer API](https://explorer.qu.ai/api) | メインネットのブロック、アカウント、トークン、検証ステータスを照会するための開発者 API ポータル。 |
| [Supply ダッシュボード](https://supply.qu.ai/) | QUAI・Qi のリアルタイム流通供給量、Polaris / Singularity ジェネシス焼却、排出スケジュール。 |
| [SOAP ダッシュボード](https://soap.qu.ai/) | Project SOAP のマージマイニング補助金流入と累計 QUAI 焼却量のライブ表示。 |
| [ネットワーク統計](https://stats.quai.network/) | メインネットのノード数とハッシュレート統計ダッシュボード。 |
| [GraphQL エンドポイント](https://graph.quai.network/) | フィルターとページネーション付きでチェーンデータを照会できるメインネット GraphQL エンドポイント。 |
| [変換ダッシュボード](https://conversions.quai.network/) | ライブのプロトコル QUAI ↔ Qi 変換レート。 |
