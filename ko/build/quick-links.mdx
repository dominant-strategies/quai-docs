## 메인넷 인프라

| 리소스 | 설명 |
| :--- | :--- |
| [Quai Explorer](https://explorer.qu.ai/) | Quai 네트워크 메인넷 공식 블록 탐색기 (블록, 워크셰어, 토큰, 컨트랙트 검증). |
| [Quai Explorer API](https://explorer.qu.ai/api) | 메인넷 블록, 계정, 토큰 및 검증 상태를 조회할 수 있는 개발자 API 포털. |
| [Supply 대시보드](https://supply.qu.ai/) | 실시간 QUAI 및 Qi 유통량, Polaris/Singularity 제네시스 소각 및 발행 일정. |
| [SOAP 대시보드](https://soap.qu.ai/) | 실시간 Project SOAP 병합 채굴 보조금 유입 및 누적 QUAI 소각량. |
| [네트워크 통계](https://stats.quai.network/) | 메인넷 노드 수 및 해시레이트 통계 대시보드. |
| [GraphQL 엔드포인트](https://graph.quai.network/) | 필터 및 페이지네이션으로 체인 데이터를 조회하는 메인넷 GraphQL 엔드포인트. |
| [변환 대시보드](https://conversions.quai.network/) | 실시간 프로토콜 QUAI ↔ Qi 변환 비율. |
