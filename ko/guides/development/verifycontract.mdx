## 소개

이 가이드는 Quai 네트워크의 공식 메인넷 블록 탐색기인 **[Quai Explorer (`explorer.qu.ai`)](https://explorer.qu.ai/)**에서 배포된 스마트 컨트랙트를 검증하는 방법을 설명합니다.

스마트 컨트랙트를 검증하면 소스 코드와 ABI가 온체인에 공개되어, 사용자와 개발자가 바이트코드를 감사하고 탐색기 내부에서 직접 **Read** 및 **Write** 컨트랙트 탭과 상호작용할 수 있습니다.

<Note>
  **Orchard 테스트넷** 배포(`chainId: 15000`)의 경우 [orchard.quaiscan.io](https://orchard.quaiscan.io/)의 Orchard 탐색기를 사용하세요.
</Note>

## Quai Explorer에서 지원하는 검증 방법

[Quai Explorer](https://explorer.qu.ai/)는 세 가지 컨트랙트 검증 워크플로를 지원합니다.

- **Solidity (Standard JSON Input)** *(권장)* — 컴파일러의 Standard JSON 입력(또는 `@quai/hardhat-deploy-metadata`로 생성된 IPFS 메타데이터 파일)을 업로드합니다.
- **Solidity (Flattened Source Code)** — 단일 파일로 평탄화된(flattened) Solidity 소스 코드를 컴파일러 버전 및 최적화 플래그와 함께 붙여넣습니다.
- **Sourcify 가져오기 (Sourcify Import)** — Sourcify에서 검증된 컨트랙트 메타데이터 및 소스 파일을 자동으로 가져옵니다.

## 필수 조건

IPFS 메타데이터와 함께 컨트랙트를 배포하고 Quai Explorer에서 검증하려면 다음 도구가 필요합니다.

| 종속성 | 설명 |
| :--- | :--- |
| [**Node.js**](https://nodejs.org/en/download/) | JavaScript 런타임 환경 (LTS 버전 사용). |
| [**hardhat-example**](https://github.com/dominant-strategies/hardhat-example) | Quai 네트워크용 샘플 컨트랙트와 배포 스크립트가 포함된 Hardhat 프로젝트. |
| [**hardhat-deploy-metadata**](https://github.com/dominant-strategies/hardhat-deploy-metadata) | 배포 중 컨트랙트 메타데이터를 IPFS에 업로드하는 Hardhat 플러그인. |
| [**Quais SDK**](https://www.npmjs.com/package/quais) | Quai 네트워크와 상호작용하기 위한 JavaScript/TypeScript 라이브러리. |

## 단계별 실습

이 실습은 [hardhat-example](https://github.com/dominant-strategies/hardhat-example) 저장소를 사용하는 [Solidity로 배포하기](/ko/guides/development/solidity) 가이드를 따릅니다.

### 1. 스마트 컨트랙트 배포

[Solidity로 배포하기](/ko/guides/development/solidity) 가이드에 따라 IPFS 메타데이터를 활성화한 상태로 스마트 컨트랙트를 배포합니다.

```bash
npx hardhat run scripts/deployERC20.js
```

출력 예시:

```text
File added with CID: QmPCoBa1bCFmRoTD7GuexJqBAy7pqg8J4b8B48q5DgxUEV
Original IPFS hash found in bytecode: QmPCoBa1bCFmRoTD7GuexJqBAy7pqg8J4b8B48q5DgxUEV
Metadata JSON for ERC20 saved to /../hardhat-example/Solidity/metadata/ERC20_metadata.json
Transaction broadcasted:  0x0032004cc6a910b8733ad9502caa315beb74f3409bee2b481116bddfb9c8880d
Contract deployed to:  0x0015dFe3280783CD9b126D8E0ccc728B6490b2b2
```

배포된 **컨트랙트 주소**와 `ipfs.qu.ai`에 업로드된 **IPFS CID**를 모두 기록해 두세요.

### 2. 포맷된 IPFS 메타데이터 다운로드

`@quai/hardhat-deploy-metadata`를 사용하는 경우, 배포의 CID를 이용해 `ipfs.qu.ai`에서 포맷된 메타데이터 JSON을 다운로드합니다.

```bash
curl https://ipfs.qu.ai/ipfs/[YOUR_IPFS_METADATA_HASH] > ipfsMeta.json
```

### 3. Quai Explorer에서 검증 및 게시

1. **[Quai Explorer (`explorer.qu.ai`)](https://explorer.qu.ai/)**를 열고 **Contract Verification** 페이지로 이동합니다(또는 배포한 컨트랙트 주소를 검색한 뒤 **Contract → Verify & Publish** 탭을 엽니다).
2. 배포된 **컨트랙트 주소**를 입력하고 소스 파일의 `SPDX-License-Identifier`와 일치하는 **라이선스**를 선택합니다.
3. 검증 방법으로 **Solidity (Standard JSON Input)**을 선택하고 컨트랙트 컴파일에 사용한 정확한 **Solidity Compiler** 버전을 선택합니다(원하는 경우 **Flattened Source** 또는 **Sourcify** 선택 가능).
4. `ipfsMeta.json`(또는 Standard JSON 입력 파일)을 업로드하고 **Verify & Publish**를 클릭합니다.

검증이 완료되면 [explorer.qu.ai](https://explorer.qu.ai/)의 컨트랙트 페이지에 검증 배지, 전체 소스 코드, ABI, 그리고 인터랙티브 **Read Contract** 및 **Write Contract** 탭이 표시됩니다.

<Tip>
  프로그래밍 방식의 검증이나 컨트랙트 ABI 조회가 필요하신가요? [Quai Explorer API](https://explorer.qu.ai/api)를 확인해 보세요.
</Tip>
